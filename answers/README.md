# answers - Tutorial 13 の答え合わせ用フォルダ

Tutorial 13「システム設計を学ぼう」で自分が作る設計書の、解答例が入っています。教材の答え合わせに載っているものと同じ中身です。

## このフォルダは、アプリの一部ではありません

`app/` や `routes/` に入っているアプリのコードとは関係がありません。設計の練習の答えを置いてあるだけなので、アプリの動きには一切影響しません。Tutorial 14 以降でこのアプリに機能を足していくときも、このフォルダは読まなくて構いません。

## 使い方

まず自分で作ってください。そのうえで、次のどちらかのときに開きます。

- **答え合わせ**: 自分が `docs/` に作ったものと、同じ章のフォルダを並べて見比べる
- **追いつく**: 前の章の成果物が手元にないまま次の章の演習に入るとき、その章のフォルダを `docs/` にコピーする

```bash
# 例: Chapter 3 の成果物を手元に用意する
cp answers/13-3/* docs/13-3/
```

図（`.drawio`）は draw.io で開けます。`https://app.diagrams.net/` を開き、「ファイル」→「開く」→「デバイス」から選んでください。自分の図の隣に並べると、四角の数と線のつなぎ方を見比べられます。

## 中身

| フォルダ | 章 | 入っているもの |
|:---------|:---|:---------------|
| `13-2/` | 機能設計 | 機能一覧・確認事項リスト・ユースケース図・ユースケース記述 |
| `13-3/` | 画面設計 | 画面一覧・画面遷移図・ワイヤーフレーム・画面項目定義・入力チェック表・メッセージ一覧 |
| `13-4/` | APIと権限の設計 | API設計書・権限マトリクス |
| `13-5/` | データ設計 | 概念モデル・ER図・CRUD表 |
| `13-6/` | 振る舞いの設計 | シーケンス図・状態遷移図・遷移表・例外一覧 |
| `13-7/` | 構造の設計 | クラス図・構造図 |
| `13-8/` | テスト設計 | テスト観点表・テストケース |

ファイル名の先頭が題材です。`post-` は配布されているこの投稿アプリ、`cafe-` は章末演習のカフェのモバイルオーダーアプリ、`register-` は会員登録のテスト設計です。
