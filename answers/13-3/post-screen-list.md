# 投稿アプリ 画面一覧

| ID | 画面名 | 役割 | 主な利用者 |
|:---|:-------|:-----|:-----------|
| SC-01 | トップ画面 | ログインしていない人にはログインと新規登録の入口を見せ、ログインしている人には名前と投稿一覧への入口を見せる（最初に開く画面） | 利用者 |
| SC-02 | ログイン画面 | メールアドレスとパスワードを入れてログインする | 利用者 |
| SC-03 | ユーザー登録画面 | 名前・メールアドレス・パスワードを入れて登録する | 利用者 |
| SC-04 | 投稿一覧画面 | すべての投稿を新しい順に見せ、自分の投稿にだけ編集と削除の入口を出す | 利用者 |
| SC-05 | 投稿編集画面 | 自分の投稿のタイトル・カテゴリ・本文を書き換える | 利用者 |
