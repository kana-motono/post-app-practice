# 投稿編集画面 画面項目定義

| 項目名 | 種類 | 必須 | 内容 |
|:-------|:-----|:-----|:-----|
| 画面見出し | 表示 | - | 「投稿編集」 |
| タイトル | 入力（1行） | 必須 | 投稿のタイトル。開いたときは今の値が入っている |
| カテゴリ | 選択 | 必須 | 登録されているカテゴリから1つ。開いたときは今のカテゴリが選ばれている |
| 本文 | 入力（複数行） | 必須 | 投稿の本文。開いたときは今の値が入っている |
| 更新ボタン | ボタン | - | 押すと書き換えを保存し、投稿一覧画面へ移る |
| キャンセルリンク | リンク | - | 押すと保存せずに投稿一覧画面へ移る |
